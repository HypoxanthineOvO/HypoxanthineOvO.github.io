项目 / vspi

VSPi

面向 Pi coding agents 的中文终端界面，把多会话、模型切换与只读工作流状态收进一个紧凑 TUI。

和 coding agent 对话的默认入口。多会话并行、模型按需切换、工作流状态只读呈现——一个终端窗口装下每天和 agent 协作的绝大部分操作。

它是自维护的 agent core：没有发布节奏，没有 roadmap，痒了就改。所有交互都按"我每天怎么用它"来取舍，因此它也成了其他 Hypo-* 工具最早的试验场。
