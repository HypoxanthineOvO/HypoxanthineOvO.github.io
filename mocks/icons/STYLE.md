# 项目图标统一风格

用于个人网站 hypox.cn 的项目卡片，显示尺寸约 48–96 px，需要缩小后依然清楚。

- 画幅：正方形 1:1，1024×1024，PNG。
- 形式：一个圆角方形的应用图标（类似 macOS 应用图标），四角圆角约 22%，图标外留透明或纯米白（#f5f1ea）背景。
- 画风：扁平矢量插画加轻微立体感（一层柔和的高光与投影），线条干净，不要照片质感，不要渐变彩虹，不要 3D 渲染的塑料感。
- 主体：图标中央只有一个简洁、可识别的符号，占画面约 60%。不要出现任何文字、字母、数字、Logo 水印。
- 色彩：整套图标共享一个底调——米白纸色、墨黑、朱红（#a3292a）作为全套的统一点缀；每个图标另有一个自己的主色（见各自说明）。
- 一致性：同一套图标要像同一个设计师画的：同样的圆角、同样的光照方向（左上光）、同样的描边粗细。
