# 发布资源优化

`pnpm build` 负责完整生产流程：Astro 静态构建 → 字体子集 → 响应式图片 → 资源预算 → 内部链接检查。GitHub Pages 的部署工作流使用同一入口。

开发仍使用完整 Fontsource 包和 `public` 原图，不编辑源字体。首次构建需要 Python 3.10+（CI 固定 3.12）、venv 和网络；脚本自动在 `.venv-build` 安装固定版本的 FontTools/Brotli。后续依赖未变时复用环境。Node/pnpm 版本遵循 package.json。`pnpm dev` 不需要 Python。

## 字体

扫描实际生成页面、属性、内联与关联 JavaScript，以及 CSS。覆盖文章文字、按钮状态、项目演示等动态文案；生成共享字符与各页面额外字符的 WOFF2，保留字体家族、字重和排版依赖。跳过无字体的跳转页。原字体支持的字符若在合并或裁剪后丢失，构建失败。源字体原本不支持的字符继续使用既有系统字体回退。

扫描不能预知未来来自外部接口的任意文本。如果增加运行时远程文字，必须补充可预知字符集或提供完整回退字库，不能仅依赖构建时页面内容。输出许可文件随生成字体发布。

## 图片与加载

从原图自动生成多尺寸 WebP，通过 srcset/sizes 让浏览器选择。PNG 采用无损编码，避免损伤图表文字；已有动画和小图标不改。原始下载链接及动态资源保留，生成变体不会覆盖原图。不同尺寸提高了服务器上的文件数量，但单次浏览只选择所需尺寸，部署目录大小不等于访问流量。

首页首屏直接显示；后续卡片图使用原生懒加载。MC 轮播只准备当前和下一张，离开视区/后台时暂停。封面保留已确认静态插画，取消原 MP4 下载；角色局部动画尚未制作，不用整图摇晃代替。

不做通用的盲目 CSS purge：项目演示含运行时创建的类名。当前最大 CSS 节省来自替换字体声明。未调整托管/CDN 设置。

## 验证与复测

- `pnpm check`
- `pnpm build`：产物包含 font-subsets.json、image-optimization.json 和 performance-budget.json，内部链接也自动检查。
- `python3 -m http.server 4173 -d dist`，另一终端 `node scripts/validate-site.mjs`：页面、交互、手机布局和无脚本封面。
- `pnpm benchmark dist /tmp/myweb-performance.json`（或直接 `node scripts/benchmark-performance.mjs dist /tmp/myweb-performance.json`）：桌面/手机各三次，冷缓存、1.6Mbps、150ms 延迟、4倍 CPU 减速、30秒窗口，本地 gzip 静态服务。浏览器需先安装 `pnpm exec playwright install chromium`。

比较前后时须使用同一脚本、机器和网络模拟。记录未完成请求，不能把尚未下载完的旧版资源误认为已省下；手机首屏 LCP 往往是文字，与桌面的封面 LCP 不可混比。本地实验不包含公网 DNS/TLS/CDN 延迟。

## 2026-10-23 对比结果

以下是同机、同条件三轮中位数，详细分类记录在 `performance-results.json`。旧版30秒结束仍有一个视频请求未完成，因此流量是窗口内接收量，不是最终总下载量。

| 指标 | 原版 | 优化后 |
|---|---:|---:|
| 桌面 FCP | 4.720 秒 | 0.992 秒 |
| 桌面 LCP | 27.340 秒 | 3.152 秒 |
| 手机 FCP | 4.728 秒 | 0.864 秒 |
| 手机 LCP | 5.612 秒 | 0.864 秒 |
| 桌面30秒接收字节 | 5.86 MB | 1.33 MB |
| 手机30秒接收字节 | 5.86 MB | 1.12 MB |
| 字体请求数 | 96 | 15 |
| 字体传输字节 | 3.37 MB | 0.91 MB |
| 样式传输字节 | 334 KB | 24 KB |

字体尚未按每种字重精确到可见DOM字符拆分；当前方案为保持所有页面、交互文字和原有八种字重，采用保守字符集。最初500–800KB首屏资源设想未完全达到，实际以上述结果为准；未通过换系统字体或模糊图片追求更小数字。

视觉回归：相同视口、字体加载完成、减少动态效果条件下，主标题、介绍、导航、卡片标题和研究标题的逐字符坐标与尺寸最大差为0，封面外框尺寸和位置不变。完整页面交互、手机菜单、研究时间线、无脚本封面及386个HTML的内部链接检查均通过。
