给"AI 写、人读、机器渲染"三类消费者同时服务的文档系统：一套结构化 Markdown 规范，配 parser、Web 与 LaTeX 双渲染器，以及 Desktop 和 VS Code 两个编辑面。

目标是让同一份源文档既能变成网页，也能变成可打印的 LaTeX成品，还能被 agent 稳定地读写。
