# Hypo-Writer 公众号内容必须进入网站

`Workspace/Hypo/Hypo-Writer` 是个人网站的正式内容源。微信公众号文章不能缺失，必须进入首页写作精选、完整 Writing/Archive、文章详情与站内搜索，并尽量保留可核验的发布时间、系列、摘要、封面和原始发布链接。任何 `.secrets` 内容均不读取、不复制、不发布。
